# v0.0.14 源码版本

版本为 `0.0.14+14`。本次更新在线音乐。

- 播放条显示同步歌词和可用译文，支持按歌名、歌手及已知时长跨渠道匹配。
- 歌曲可加入指定歌单、播放队列或安排为下一首。
- 搜索结果默认合并同名同歌手的歌曲。设置提供平衡、延迟优先和音质优先策略，可分别关闭聚合和自动换源。
- 队列后台检测音频可用性，播放卡顿时尝试同曲其他渠道并恢复进度。
- 风格歌单支持网易云、QQ 音乐和酷狗的公开曲目元数据，播放时通过现有渠道匹配。

音乐模块最终通过 86 项。Windows 原生验证覆盖公开音频解码、歌词和离线连播。Android/TV 真机、公网长时换源及读屏待验收。详见[实施状态](STATUS.md)。
