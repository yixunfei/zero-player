# 使用指南

## 来源与搜索

内置渠道现包含看剧AI（kanju3.com）和 555（wu5mv.com），支持搜索、分类、分页、详情、选集与公开直连线路播放。播放和下载前会重新解析地址；原站要求账户或外部解析的线路会提示不支持。已有安装会补入新渠道并保留原有停用选择。

首次启动自动导入内置渠道，并依据随包本地预检设置默认启停：明确错误的渠道不默认启用，超时等未确定结果保留。之后保留你的手动启停和移除选择。「恢复内置默认」会提示并重新应用预检默认值。「视频源」支持多选、全部启用/停用/移除、显示已移除及恢复内置源。也可手动添加 CMS API，或预览订阅后选择启用。TVBox 多仓是目录，需展开并选择受支持的 CMS，不执行远程脚本。候选存在不代表可播放；Spider/JAR/脚本解析站显示跳过原因。接口探活、媒体首包速度、实际解码分辨率分别显示。

订阅刷新保留个人启停、覆盖与删除意图，多个订阅可共享来源。订阅连续失败三次暂停，保留旧快照；来源失败会退避，可手动恢复。公开分享每次预览并确认，带请求头或地址凭证的条目默认排除。

搜索并发可配置 1–16 路（默认 6），逐源返回，切换关键词取消旧请求。影片同义分类合并为一张卡，保留不同来源；明确年份、季数、剪辑版本冲突分开。缺失年份仅在同名结果中存在唯一明确年份时并入；自动下载换源使用更严格身份判定。成人过滤检查来源分类和标题/分类关键词，不能识别所有漏标内容。

后台源检测默认开启，检测并发可配置 1–6 路（默认 3），每 30 分钟检查是否需要更新，仅重测超过 6 小时的结果，尊重退避。显示 API 延迟、最后检测时间、主站标题/域名；API 成功不等于媒体可播放。检测是应用运行期间的异步任务，不是 Android 常驻服务。

## 主题与全屏

默认影院黑金，可选柔和暖白、青灰深色和跟随系统。界面默认小赖字体，在设置的「界面字体」可选小赖、思源黑体 / Noto Sans SC、思源宋体 / Noto Serif SC、系统字体，立即生效并预览保存；前三种字体均已离线内置。默认启动即进入应用沉浸全屏，可在设置「启动时沉浸全屏」关闭，下次启动生效。顶栏全屏按钮/F11 切换当前会话应用全屏；播放页 F 切换播放全屏。应用全屏与播放器全屏分别保存当前会话状态。

## 播放

换线路/来源按集数语义匹配，无法唯一确认时要求选集。历史续播重新请求详情。进度每四秒及暂停、退出、Windows 正常关闭时保存。

播放控件覆盖在画面上，播放中静置 3 秒自动隐藏；单击/移动鼠标/键盘唤醒，暂停和出错时保持可见。右侧锁按钮开启防误触，Escape/返回先解除锁定。顶部设置按钮打开选集与设置面板，持续提供换源与源屏蔽入口。屏蔽不打断正在播放的本集，但阻止后续搜索、换源和新下载，可在源管理中重新启用。

HLS 主清单有多个真实版本时可选择分辨率/码率或自动，保留音轨和字幕分组并恢复播放位置；单画质源不会显示虚构清晰度。

手机横滑预览跳转，松手后执行；右半屏竖滑调音量，左半屏调画面遮光亮度（不是系统硬件亮度）。手势可关闭。长按临时 3 倍速，松开/取消恢复；键盘 Space 播放暂停，J/L 前后 10 秒，F 全屏，Escape 返回。方向键移动焦点、Enter/确认操作，电视用系统输入法。硬件遥控器全流程待验证。

片段支持标签和时间编辑、试跳暂停、逐剧开关及撤销；不同版本受时长匹配保护。广告过滤默认关闭，只处理保守支持的显式 CUE 标记静态单 TS 清单，其他清单保留原样。

Android 小窗用系统 PiP；Windows 小窗置顶缩小，再点恢复。Android PiP、截图保存、横竖屏及 TV 交互等待设备验证。

## 直播和发现

内置直播保留原有六个独立列表，并补入 HerbertHe/iptv-sources 国内列表、fanmingming/live 综合 / ITV / IPv6 列表、ssili126/tv 列表，共十一份。进入直播页默认打开央视分组并选中 CCTV-1，不自动播放；点击或确认后才播放。央视按数字自然排序，之后是卫视；最近按观看时间排列。首次进入直播页下载频道；失败可在「管理订阅 / EPG」单独重试，或用「恢复 / 刷新内置直播」恢复并更新。支持 M3U 和 TXT（名称,地址）订阅；刷新失败、空列表或验证网页不会覆盖已有频道。

「在线电视 IPTV 搜索」接入 Tonkiang：输入频道名称，按需翻页、勾选结果并导入，随后在直播页测活。遇到验证或网络超时，可复制原站搜索链接，在浏览器搜索后复制结果文字或保存 HTML，再用粘贴 / 文件导入。搜索结果是选择保存的频道快照，管理页刷新会重新打开搜索供选择，并合并导入的线路。

导入频道 M3U，可配 XMLTV/XML.GZ，支持相对地址、备用线路、User-Agent/Referer、分组、收藏及最近观看。消失的收藏显示暂不可用；重新出现时恢复。EPG 按 tvg-id 匹配，无节目单仍可播放。

检测当前分组最多 100 个频道、两个并发，每频道最多尝试三条线路，每路 256 KiB 样本 / 20 秒有效网络时间，可停止。任一路有媒体响应即可通过；超时、限流、临时服务错误及未查完备用路记为未确定，不自动停用。检测记录和首包延迟持续保存，成功线路下次播放优先。可以单频道停用/恢复，或在检测完成后确认停用明确不可用频道。

宽屏直播采用分组、频道和信息三栏，手机采用横向分组。方向键移动焦点、确认播放，频道操作菜单提供收藏、节目单、检测和启停；已停用频道在「已停用」分组恢复。直播管理 → 管理订阅 / EPG 可停用整份订阅并暂停自动刷新，保留数据和收藏，也可手动重检。导出保留备用线路和标准 VLC 请求头，模型以频道统一请求头为准。

首页包含主推海报、继续观看和影片网格。推荐频道可切换至已启用 CMS 的内容列表，分类使用接口实际返回数据；AI 剧场仅在所选源声明时展示。推荐可选豆瓣（电影、剧集、动画、美剧、英剧、国产剧、韩剧、日剧、综艺、纪录片、短剧、儿童、动作、喜剧、科幻、悬疑）、Bangumi、60s 或关闭；新番按星期浏览，榜单包含电影/剧集/综艺及百度热播。失败显示缓存或错误，搜索仍可用。

### 默认频道、聚合与加载更多

默认推荐数据来自豆瓣；首页明确显示「豆瓣精选」，它只提供发现榜单，选中作品后再搜索可用播放源。可以改为 Bangumi、影视榜单，或选择已启用的 CMS 频道。选择频道和「单类浏览 / 分类聚合」后点「设为开屏默认」，也可在设置中的「默认开屏频道」「开屏使用分类聚合」修改。默认源失效时临时回退，不删除已保存偏好。

「分类聚合」在当前频道的真实分类中轮流追加内容，覆盖频道声明的全部分类；每批至多两个请求，相同作品 ID 去重，不混入无法证实的分类。单类模式可浏览该频道的全部分类。接近列表底部自动加载下一页，也保留「加载更多」按钮；下拉或点击刷新会重置列表。固定榜单和新番日历没有真正分页时直接显示结束。

自动加载达到 240 部后暂停，保留当前完整页（可能略超 240），点击「再加载 N 部」继续加载，并显示流量和内存提示。设置 → 每次手动加载条目可选 12 / 24 / 48 / 96 / 120 / 240，默认 48；不足时显示剩余内容，上游整页多出的条目留待下一批，不丢失。重复页/尾页停止，失败保留已有内容并支持手动重试。切换频道、分类、布局或离开首页会取消旧请求；网格按需构建。封面请求最多 4 路、单张最多 3 MiB，压缩图片缓存 16 MiB/80 项，解码缓存 64 MiB/120 项。退出卡片取消无人使用的下载，设置中的清理缓存也清理图片缓存。缓存预算不等于应用总内存上限。

豆瓣封面采用独立的公开图片请求头，返回 HTML 或请求失败时显示「封面暂不可用 · 重试」，不会把验证页当作图片；无需关闭证书校验。公共 CDN 仍可能限流，可以重试或换频道。

## 缓存、离线与导出

缓存预算和前向窗口可设，下载分片受保护。单集预算按完整分片计数，可能超过设置值一个在途分片；总缓存有硬上限。存储不足时播放回退直通，下载失败保留已完成资源。

详情点击「下载选集」，支持全选、反选和多选加入队列。支持静态 HLS、MP4 及可识别的无扩展名地址，支持排队、暂停、恢复、重试。恢复重新解析集数；清单内容变化拒绝混合版本。默认失败后尝试最多 3 个其他来源，匹配同作品、年份/创作信息、版本和语义集数，不确定时保留失败供用户处理。换源使用独立目录重新下载整集，不拼接不同来源的字节或分片。多源并发默认关闭，只有在设置或下载面板明确开启后才按整集分配来源，并发 1–4 集（默认 2），共用容量预算；没有匹配来源时继续使用原来源。动态直播和 DRM 不支持整集离线。

Android 下载仅前台运行，退后台暂停，返回后可手动继续；计费网络默认暂停。完成任务有哈希校验。导出使用 FFmpeg 重封装并完整解码验证，不自动转码。Windows 五类 HLS×MP4/TS 已验证，Android 待实测。

## 数据

本次个人备份格式更新为版本 2，包含直播订阅请求头、频道健康与启停、整份订阅启停；版本 1 的旧备份不再导入，请从当前数据重新导出。数据库中的现有设置、来源和播放记录保持原位。

个人备份含设置、源、历史、进度、直播偏好等，可能含凭证，不应公开。导入先预览并事务化替换，错误回滚。不包含下载任务/视频，窗口尺寸不随备份迁移。Windows 使用系统 application support 目录，Android 使用应用私有目录；卸载前备份所需内容。无跨设备自动同步。


## 2026-10-27 交互增强

桌面与平板导航改为覆盖式抽屉，不占用内容栏。点击左上菜单、按 Ctrl+M 或菜单键展开；桌面鼠标停留左边缘 250 毫秒展开，移出悬停打开的菜单后关闭。全屏默认收起抽屉；菜单和全屏按钮位于独立顶部栏，不遮挡标题。顶部栏与首页分类向下滚动时收起，向上滚动时出现。手机使用紧凑底部导航。

推荐横幅使用现有封面铺满背景并柔化裁切，桌面额外保留清晰海报；没有伪造或自动下载宣传剧照。封面支持鼠标悬停、键盘焦点展开简介；触摸设备点击信息角标切换。来源无简介时显示占位说明。电视模式增加卡片尺寸与字体，系统减少动画设置作用于封面和播放器渐变。

播放工具栏直接提供音量、静音、倍速、播放暂停、前后跳转、下一集和全屏；窄屏自动换行。控制栏淡出后不接受点击或焦点；键盘操作时保留当前操作焦点，鼠标/触摸停止操作后自动隐藏。

搜索选源、播放换源时自动检测 API 延迟；影片详情及选集面板检测播放线路样本（最多两路并发，每路 256 KiB/20 秒有效网络时间，不含本地排队；收到媒体数据即结束）。API 可用、媒体有响应和完整解码是不同状态；检测结果不是完整播放保证。关闭选择器会取消检测。

首页、搜索、详情和播放失败提供「屏蔽渠道？」入口，确认后持续停用，源管理中可重新启用。搜索及首页查询记录健康信息并降低失败源优先级；连续失败沿用退避策略。屏蔽不强制中止当前播放，已停用来源不再参与自动恢复。

列表保留标题等轻量数据以支持回滚浏览；离屏 Widget 和图片租约可释放，图片采用有界缓存。不使用可能被垃圾回收打断列表顺序的弱引用；继续大量加载仍会增加列表内存。

首页滚动超过 500 像素后显示返回顶部按钮，或使用 Ctrl+Home；输入框中保留原有键盘行为。刷新也会回到顶部。分类过多时可以水平滚动选择。

豆瓣首页首推自动尝试获取简介，其他海报展开信息时才请求；成功结果有界缓存七天。豆瓣可能返回验证页面，这时显示「简介暂无法获取」，不表示作品没有简介。后台 API 检测超时属于未确定结果，不会直接增加失败次数；真实搜索/加载失败仍按健康策略降低优先级。


### 新增页面快捷键

Home / End 或 Ctrl+Home / Ctrl+End 跳到当前列表首尾，PageUp / PageDown 翻页；输入框保留光标编辑操作，弹窗不触发背后页面滚动。Ctrl+K 打开搜索；搜索页提供清空、停止、返回，Esc 搜索中先停止，否则返回，Alt+左返回，系统返回可从独立搜索页回到主页。Ctrl+M 展开导航，F11 切换应用全屏。

## 2026-10-28 渠道清理与广播后台播放

- 内置新增 MaccmsResources 的普通与成人两份列表；成人新增渠道默认停用。重复导入按接口身份合并，保留用户名称、请求头和启停选择。可在订阅列表手动更新，或通过恢复内置渠道重置默认选择。
- 点播源管理与直播页运行检测后，可一键停用或删除本次明确无效的来源；执行前会确认。网络异常、超时、取消以及未测完的来源不会进入清理集合。删除是持久移除，可从已移除列表恢复，订阅更新不会自动恢复。
- CCTV-1、CCTV-1 综合等已知别名归为一个节目，保留不同来源线路；CCTV-5 与 CCTV-5+、区域版及 4K 版保持区分。清理一个失效来源不会删除同节目其他正常来源。
- “管理广播订阅”支持添加 M3U/TXT、刷新、启停与移除。每次成功更新同时保存数据库快照与应用数据目录下 `radio_snapshots` 文件；失败和空列表不覆盖成功快照。项目中的 `assets/catalogs/radio/cn.snapshot.json` 可通过 `dart run tool/sync_radio_snapshot.dart` 显式更新。
- 点击电台星标收藏，并可用“收藏电台”筛选；收藏与订阅配置随本地备份保存。
- Windows 正在播放或连接广播时关闭窗口，会驻留系统托盘继续收听。点击图标显示窗口；右键可暂停/继续、停止广播或退出应用。停止后若窗口仍隐藏，保留托盘入口；没有广播播放时关闭窗口正常退出。
- 托盘功能针对 Windows。Android 离开广播页面可继续收听，但锁屏和系统后台服务尚未实现，不保证系统回收后的播放。第三方源的响应不等于完整节目可播放保证。
