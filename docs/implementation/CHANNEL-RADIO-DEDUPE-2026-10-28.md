# 渠道去重与广播分类（2026-10-28）

> 本文为本日早期阶段记录。后续接手已获得一起验收并提交的授权；最终渠道启停、退出修复与发行包信息见 [v0.0.2 验收记录](HARDENING-2026-10-28.md)。

## 用户确认的整理规则

同名只保留一个优选接口，其余可恢复移除。相同规范化网址自动整理；批量停用可能失效渠道必须先显示数量确认，不能自动清空不确定来源。

## 渠道实现

- SourceDuplicateStore 对规范化网址及完整显示名分组，事务内选取保留项、归档重复项、合并收藏并迁移默认频道。优先最新有效诊断，再考虑启用、收藏、HTTPS、延迟，最后用稳定 ID 排序。
- 不跨不同接口搬移影片 ID 或下载任务；历史仍引用原接口。去重归档使用已有 suppressed 状态，额外保存来源替换记录，保留接口本体和恢复入口。
- 恢复重复项会替换当前保留项，避免恢复后再次出现重复菜单。刷新订阅不自动恢复归档项。CMS XML/JSON 表示及末尾斜杠规范化；凭证查询值不被抹除。
- 忽略 Welcome、Nginx 等通用页面标题，防止无关网站因默认标题相同被合并。
- 新增“停用可能失效”数量确认；执行时再次读取状态，只处理确认范围内仍被标记且可见、启用的渠道。较新成功记录覆盖旧失败标签。
- 推荐菜单使用固定行高和有界高度定位当前项；推荐顺序改为收藏、名称、稳定 ID，探测延迟不会重排用户刚选中的项。

## 广播与页面行为

- 广播使用独立排序，不再继承直播“央视优先”的排序规则。别名归组按广播/电视类型分别执行，默认广播在前，同类收藏在前。
- 内置成功快照经过现有别名归组后为 1740 个节目：1668 个广播电台、72 个电视伴听。分类由名称和分组提供线索；未明确标识电视的普通广播订阅条目按广播展示，不推测实际媒体内容。
- 提供全部、广播电台、电视伴听筛选，卡片显示类型；原分组和搜索、收藏继续可用。
- 展开控件可折叠为迷你条；从迷你条进入广播页使用可返回导航栈，页面向下箭头返回原页面。只改变呈现与导航，不重建播放器或停止音频。
