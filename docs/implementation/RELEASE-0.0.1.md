# Zero Player v0.0.1

2026-10-27 · 首个基础版本，面向 Windows x64 与 Android arm64-v8a / x86_64。

## 本次功能

- 首页搜索并入推荐频道工具栏，保留醒目主题色边框；小屏通过“首页选项”展开其他操作。
- 使用项目所有者提供的 Logo，统一 README、应用导航、Windows 图标、Android 图标及 TV 横幅。
- 新增“在线广播（实验阶段）”，内置 popocoding/awesome-m3u 的中国广播列表。支持分组、搜索、音量、播放/暂停/停止和多线路选择，离开广播页停止播放。
- 广播列表独立缓存 24 小时，更新失败保留旧快照，不混入电视直播订阅。
- 保留聚合搜索、点播、直播、历史、离线下载/导出、首次导航引导与免责声明。

## 审查与修复

- 修复 M3U 中单条非法 URI 或台标 URI 导致整份有效列表解析失败的问题；频道显示字段也进行 HTML/实体清理。
- 防止广播快速切台或退出页面后，旧的异步初始化继续打开电台。
- 修正广播音量控件范围，并覆盖手机与桌面宽度。
- 统一应用、平台与安装器版本号；发布构建使用独立 Android 签名，缺失签名时显式失败，取消默认调试签名回退。
- 修复 Android 分架构打包与 ABI 过滤配置冲突，补齐播放器使用的 Cupertino 图标字体。
- 打包脚本按版本隔离产物；源码 ZIP 跟随经审查的 Git index。排除本地配置、签名密钥、缓存、生成代码与构建报告。
- 上一轮修复的默认全屏退出窗口隐藏路径继续通过回归；不把未复现的历史原生崩溃断言为同一原因。

## 验证

- flutter analyze 无问题；源码/函数尺寸检查通过。
- 单元与组件测试：123 项通过，2 项需公网的既有用例显式跳过。
- Windows 原生回归：全屏/引导 2 项、首页 1 项、直播/搜索/快捷键 1 项、原生导出/产品流程 2 项通过。
- 广播原生流程验证导航、搜索、暂停及离开页面释放；最终使用本地产生的纯音频样本。
- 指定公网广播列表在本次检查中可解析出 1,741 个电台；这只验证列表可获取和可解析，不代表全部电台均可播放。
- Windows x64 Release、Android 通用 APK、arm64 APK、x64 APK 与 AAB 均构建成功；APK 架构和原生库完整性检查通过。
- 三个 APK 均通过 apksigner 验签，AAB 通过 jarsigner 验签；使用相同的项目发布证书。
- 实际 Windows Release 界面验证：默认全屏启动、F11 恢复窗口、界面按钮进入及退出全屏、退出后打开说明弹窗均正常；广播列表成功加载，主页同排搜索及新图标可见。

## 安装包

- Windows：x64 安装器 EXE、便携 ZIP。
- Android：通用 APK、arm64 APK、x64 APK，以及不能直接安装的 AAB。
- 附源码 ZIP、第三方许可证、原生源码快照和 SHA256SUMS.txt。

Android 使用独立项目签名。旧调试签名安装不能直接覆盖，请先备份本地数据。Windows 程序未做商业 Authenticode 签名。

Android 发布证书 SHA-256：`7a2835b613a32dcb4d43c6b3448d453fe7c7dc5553a1abe010e1d46f84d84a06`。

## 已知范围

广播为实验功能，第三方源可能失效或有地域限制。Android 构建未连接实机或 TV 做设备验收；不支持 32 位 Android、macOS、iOS 或 Windows ARM64 原生版。测试通过不意味着所有缺陷均已排除，也不替代长时间稳定性与完整供应链审计。

原生源码附件收录 mpv、FFmpeg、FFmpegKit 及上游构建来源快照，记录地址、版本与 SHA-256；第三方依赖和工具链的来源说明继续保留在上游构建脚本与 NOTICE 中，未宣称附件覆盖整个操作系统和工具链。
