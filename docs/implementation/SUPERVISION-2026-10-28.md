# v0.0.4 成人过滤与监管模式

用户确认覆盖点播、直播和广播；每次敏感操作单独验证，无解锁会话；首次设置生成恢复码并由用户自行保存。沿用既有退出、安全网关、直播交互和搜索修复，不重新执行上轮公网频道审查。本轮仅本地提交，未推送或发布 Release。

## 统一过滤

- 独立的 ContentPolicy 供来源、列表、搜索、详情、播放、下载、历史和节目表使用。来源按接口身份屏蔽，改名不能绕过；直播/广播按已有频道身份规则屏蔽，CCTV-5 与 CCTV-5+ 保持区分。
- 修复 R18 来源仅依赖行内 group 导致的漏标：该列表全部候选强制标为成人，并对旧内置分类进行修正。CMS 缺少 type_name 时补查分类映射，不能确认的分类暂不展示或播放。
- 成人识别处理全角、零宽、部分常见繁简字、明确成人词组及英文词边界；成人教育、成人礼、Java、AV1 等正常词有防误杀断言。此功能不分析视频画面，也不能保证识别没有任何标记的内容。
- 当前来源、旧缓存和在途请求都经过规则检查；仓库中的新分类不能被旧 provider 快照覆盖。搜索规则变化取消旧请求，分类缓存有时间和数量上限。
- 播放校验选中线路对应的真实频道，当前节目标题参与过滤；规则收紧停止当前播放，关闭媒体会话并阻止暂停恢复、重试及自动换源绕过。广播的托盘恢复操作同样受限。
- 下载创建、恢复、换源、离线播放和导出再次校验；在途任务在规则变化时取消。历史和下载保留内容分类，旧历史元数据不足时隐藏而不删除。

## 凭据与授权

- Argon2id 固定使用 19 MiB、2 次迭代、1 路并行、32 字节摘要；随机盐 16 字节，恢复码随机值 24 字节。计算在 isolate 执行，避免阻塞 UI；存储中只有算法、盐和摘要。
- 凭据与规则存入独立 app_meta 记录。普通备份白名单排除此记录；恢复备份本身要求验证，不能通过备份重置监管。
- 授权作用域绑定用途、当前配置版本和操作生命周期；操作结束或配置变更后失效。敏感仓库在写入处检查授权，UI 取消不执行，后台订阅或检测不得自动启用渠道。
- 连续 5 次验证失败开始退避，30 秒递增至最多 300 秒；失败状态持久化。损坏的监管配置保持锁定。恢复码仅允许重设凭据，不能用作普通修改规则或关闭监管的密码。
- 密码/恢复码变更先生成待确认凭据，保存恢复码后才提交；重设保留规则并旋转恢复码。每次操作均重新验证，不保留已解锁状态。
- 监管模式仅保护本应用操作；拥有本机数据库修改权限的人不在保护边界内。没有加入后门密码或无验证重置入口。

## 生命周期与验收方式

初始化先加载监管和成人过滤设置，随后导入来源；关闭时取消并等待来源刷新任务，再释放规则监听器和数据库。原生验收使用独立临时 SQLite、本地受控媒体和真实 MediaKit 引擎，不给用户数据库配置测试密码。测试密码仅是隔离 fixture 常量；恢复码不写入日志或截图。

干净构建额外修复：Flutter 生成缓存积累使项目盘耗尽，使用标准 flutter clean 回收后验证完整构建。Windows SQLite 预置脚本补齐已锁定版本摘要；FFmpegKit 使用经摘要验证的本地归档。CMake 在加载插件之前固定应用构建目录，避免首次配置中断后把 Program Files 默认路径留在缓存中，也避免插件提前捕获错误安装目标。
