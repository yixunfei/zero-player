# Zero Player v0.0.7

2026-10-29（Asia/Shanghai）· Windows x64 / Android ARM64，构建号 `0.0.7+7`。

## 本版变化

- 播放中特征检测使用原受控媒体流，后台采样声画特征，支持频道/全剧规则、重新提取、确认、撤销、恢复与进度同步。过滤默认关闭，无可用规则、缺失资源或检测失败时继续播放。
- 轻量关键词、OCR 与 ASR 由设置页手动安装；基础包不包含模型或推理运行库。关键词命中先确认，默认跳过 20 秒，可调整；已确认声画规则遵循所选策略。
- 修复监管下订阅刷新越权新增直播列表、复合成人分类漏判、备份内容标签遗漏和恢复后策略未通知；敏感设置取消/密码错误时显示真实已保存值。
- 修复重叠强特征漏跳尾部、缺失音轨/画轨导致另一模态失效、关键词跨采样片上下文和 seek 重置、稀疏长特征回看、低置信 OCR 屏蔽后续确定证据、ASR stream 生命周期及跨频道规则数量校验。
- 完善移动端导航、搜索、来源选择与播放控件布局，保留三套字体。Android ARM64 压缩原生库以控制下载体积。
- 应用设置、许可证、诊断信息与构建清单统一版本，发布工具核验 APK 内嵌版本，避免旧产物混入新版。

详细修复依据见 [审核记录](REVIEW-20261029.md)。

## 范围与限制

- 本次无已连接 Android 设备，未完成 Android 实机播放、模型加载、全屏系统栏与性能验收；构建、签名和包体检查不能替代实机验收。本次不发布 Android x64、通用 APK 或 AAB。
- 成人过滤依赖来源分类及文本元数据；声画规则只匹配已有样本，OCR/ASR 检测文字和口播，不包含对无文字成人或暴力画面的通用识别。
- 合成素材用于验证实现链路，不代表真实来源的识别准确率；变速、混音、遮挡等可能漏检，相似内容可能误判。长规则回看可能增加耗时，不承诺即时命中、零卡顿或零下载。
- 公开来源可用性未作为本地回归保证；广播仍为实验功能。Windows 二进制未做商业 Authenticode 签名。Android 延用项目既有发布签名。
