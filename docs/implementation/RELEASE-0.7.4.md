# v0.7.4 预发行

应用版本为 `0.7.4+74`。Windows x64 提供安装器和便携包；Android ARM64 仅提供独立包名、测试签名的开发测试 APK，不能覆盖正式 Android 版本。源码、第三方声明、原生组件来源和 SHA-256 清单随版附上。

- 网络阅读新增图片章节、漫画与有声书入口、图文混排、离线阅读及导出；改进搜索、目录、换源和阅读缓存。
- 章节下载在离开详情页后继续运行，完成后自动清理任务；失败或暂停保留续传计划。文字下载及续传最多 3 章并发，漫画和听书最多 2 章并发。新增下载管理页，可查看进度、暂停、续传、移除计划和删除离线内容。
- 书架新增本地离线、在线阅读、有更新及作品类型筛选。选择“有更新”时检查当前书架中的在线作品，包括未加入追更的作品。
- 书籍封面增加有界磁盘与内存缓存，设置页支持容量选择、用量查看和清理。手机端阅读标题、搜索和渠道操作在窄屏分行显示。
- UU 看书当前对实网请求返回 403，新安装默认关闭，可在来源管理中手动启用；不删除已有书籍和用户设置。

已通过全量 Flutter 测试、静态分析及窄屏定向回归。Windows 原生实网回归本次未通过：UU 看书返回 403，Gutenberg 有声文件传输中断；这些属于当前外部来源可用性边界。Android/TV 实机、系统挂起后的后台下载及真实用户书源长期稳定性尚未验收。最终构建和附件校验记录见[实施状态](STATUS.md)。
