# 0.0.5 监管展示与网站信息修复

日期：2026-10-28。平台：Windows x64。

## 问题和证据

- 用户反馈“森林、鲨鱼”仍出现在首页；补充要求从节目展示阶段移除受限条目，详情不能提供外部网站访问线索。
- 旧策略中成人过滤只取普通设置值，监管开启本身不会强制过滤。重新开启监管或恢复关闭过滤的旧偏好后，策略可能弱化。
- 首页只监听监管开关，没有监听统一内容策略中的来源分类更新；打开的 Flutter 下拉菜单还可能保留旧选项。
- `slapibf.com` 在本机来源表中为 unknown；2026-10-28 只读分类接口返回多项明确成人分类，已据此补充来源级证据。`shayuapi.com` 的来源级依据为项目内 `assets/catalogs/maccms/R18.json`。不使用“森林”“鲨鱼”这些普通词作为标题黑名单。
- 来源详情、管理卡片、搜索状态缓存、换源选择器和个人备份存在展示网址或旧条目的旁路。

## 修复

1. 监管开启时强制成人过滤；存储层拒绝关闭过滤。旧偏好、重启、备份恢复和单次渠道启用授权不能解除这条规则。设置界面展示实际生效状态。
2. 成人来源按已验证域名和来源分类识别；探测发现至少三个不同成人类别且无主流影视类别时，持久化为成人来源。已确认来源即时影响全局内容策略。混合影视目录继续使用作品级过滤。
3. 首页和默认频道列表立即移除受限选项，已打开下拉菜单同步销毁；取消受限来源的旧搜索结果、分组缓存、状态信息和优先来源提示。
4. 管理页仅保留匿名的“受限频道”操作卡片，隐藏名称、域名和错误信息，仍可停用或经单次验证启用。详情/编辑入口仅显示禁止访问提示；已经打开的详情在规则变化后立即隐藏网址、IP、请求头和诊断。
5. 换源候选和探测反馈同样遵循策略。公开分享过滤受限来源；包含完整来源网址的个人备份需独立、仅本次有效的密码授权。
