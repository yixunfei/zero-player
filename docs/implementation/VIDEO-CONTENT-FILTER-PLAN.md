# 播放中内容过滤：实施计划与设计审查

## 第三阶段：流畅优先与移动端优化（2026-10-29，当前策略）

用户确认：缺少特征/模型或检测失败继续播放；优先轻量离线关键词，资源首次手动下载；OCR 可选；保留全部字体；卡顿设备为 Android 平板，主要发生在列表、搜索和页面操作。以下阶段为历史记录，严格隔离、首播等待及播放视频重编码不再是当前入口策略。

- 播放器直接打开原受控网关流，后台单任务检测、取消和过期结果隔离。无规则/模型只显示状态，命中后按检测起点与步长跳过，支持撤销。默认关键词使用量化 KWS，默认步长 15 秒。
- 新音频规则默认声音匹配；只计算实际需要的声画模态。FFT 复用窗函数、旋转因子、频段索引和缓冲区；桌面 4 秒音频指纹基准由 2.57ms 降为 1.13ms，输出摘要一致，该数字不代表 Android 实测。
- 搜索进度通知合并至 120ms，状态变更不重复排序；海报网格按可见范围构建。修复 320px / 1.6 倍文字下的规则输入溢出与长播放错误面板溢出。
- Android 发布构建尊重所选 ABI，启用资源/代码压缩。手机专用 arm64 包按 100 MiB 预算核验；双 ABI 通用包仍更大，三套现有字体全部保留。
- 详细验收、安装方式、尚待实机验证项见 [本轮记录](MOBILE-FILTER-20261029.md)。

## 第二阶段历史记录：用户确认的轻量化调整

2026-10-28：默认使用无需模型的画面感知哈希和音频频谱指纹；播放中标记样本，按同渠道复用，可选画面、声音或共同匹配。跳过范围为命中样本起点减前偏移、终点加后偏移，支持预览、启停、删除。前偏移需要保留尚未发布的回看窗口，不能删除已经显示的画面。OCR/ASR 改为用户在设置中手动下载的可选增强，播放不发起资源下载；模型与额外推理库移出基础分发包。沿用严格检测门禁与 Android 实机验收延期约定。

### 当前实现

- 纯 Dart DCT 感知哈希、RGB 均值与对比度辅助；音频采用 16kHz 单声道、250ms 分窗的 24 段对数频谱。模式可选画面、音频、两者共同匹配，按有序样本跨 4 秒采样片段检测，不依赖外部模型。
- 规则包含来源渠道 ID、样本时长、前后偏移、签名、小 JPEG 预览和来源时间。原始采样文件采集后删除；规则保存在 app_meta，随备份导入导出且校验数量、字段和预览尺寸。监管授权覆盖编辑、启停和删除。
- 原始时间轴上的阻断区间合并，裁剪向外对齐 40ms。保留“最长样本 + 前偏移 + 4 秒”的未发布隔离窗口，命中前偏移不会追删已播放数据；不完整检测和取消不得发布隔离内容。
- 默认模型和原生推理运行库均缺省；设置页显式下载 OCR / ASR，分别启停与清理。共享 CPU 库来自固定的 sherpa 平台发布归档，压缩包及允许提取的每个二进制均验证长度与 SHA-256。播放只校验已有资源，不联网安装。
- Windows CMake 与 Android Gradle 排除全部 ORT/sherpa 原生库；Windows 还清理已知旧版 DLL。Dart FFI 绑定保留，增强检测在独立 isolate 内按绝对路径预加载已验证运行库。
- Windows 的基础路径在尚未加载任何推理库且资源目录为空时完成真实采集和播放。前后偏移样例为命中 4–6 秒、前 1 秒/后 7 秒，剔除 3–13 秒，输出 6 秒安全视频；恢复画面与原片进度映射均验证。

### 能力边界

没有真实广告渠道样本，合成素材验证仅证明实现链路和确定行为，不给出真实识别准确率。基础算法只匹配已有样本；未标注的新文字、变速/混音/遮挡可能漏检，相似版式可能误判。静态重复画面的偏移依据最早完整匹配的位置，不依据原样本的绝对位置。特征后的用户指定区间可以不再采样，但除成对 CUE 已做请求日志验证外，不宣称解复用器零下载或零卡顿。保持最高 720p/25fps 的重编码代价，功能默认关闭。

## 已确认约束与实现选择

- 检测范围为博彩、引流广告、指定口播与画面关键词；不含无文字的成人或暴力画面。
- 模型缺失、异常、超时或疑似命中但置信度不足时停止放行，不回退播放原片。
- 没有用户提供的真实素材；使用项目生成的大字广告、正常画面及本机中文 TTS 口播做可复现验证，不把合成素材结果作为真实源准确率。
- 采用 SenseVoice int8 语音识别与 PP-OCRv4 文字检测/识别，模型版本、长度、SHA256 固定，首次约 244 MiB，之后本机运行。
- 严格模式采用“隔离解码采样 → OCR / ASR → 已审核分片发布”。MP4/FLV 不能仅靠播放位置回调实现播放前门禁，因此统一生成可独立播放的本地 TS 分片。
- 每片 4 秒，目标安全缓冲 24 秒，首播准备 12 秒安全内容或剩余全部内容；每秒采样 2 张画面，整段音频做 ASR。检测通过是模型检查成功且未命中，并非绝对内容安全证明。
- 为避免 copy 模式关键帧前滚带入已拒绝片段，当前重编码为最高 720p / 25fps，音频 AAC 双声道。画质、耗电、首播耗时是明确代价；该功能默认关闭，设置页说明代价。
- 只向原生播放器提供审核通过的能力地址；已拒绝数据不进入播放器清单。播放时间重新连续编号，用户进度通过显式区间映射回原片。
- 拖动、切集、切清晰度重新创建检测会话；取消后旧检测结果不可发布。异常不触发自动换源回退。
- 不根据常见广告时长猜测结束点。没有可靠边界时必须继续检查，不宣称跳过未检测区间的网络下载。
- 可靠的成对 CUE-OUT / CUE-IN 在网关改写清单时先删除，FFmpeg 无法请求被移除的分片；采样适配器将删减时间还原为原片时间。只减少采样调用不够，实际测试证实解复用器仍会读到相邻广告分片，因此不能仅靠“未调用 sample”宣称省下载。
- 没有固定广告音乐参考样本，本轮不声称已实现可用的固定背景音乐识别。

下文保留设计审查依据。原建议中的单纯 SkipRanges 接入已由严格门禁的隔离分片管线替代；识别、调度、网络与播放控制仍保持独立模块。

## 1. 目标

在播放前方维持有界探测窗口，利用音频样本、语音文本和画面文字识别广告或指定内容，确认区间后自动跳过，并尽可能避免下载已确认区间内的媒体。检测、缓存、播放控制分别负责自己的生命周期。

不把“未检出”当作“已证明安全”，不将演示检测器或模拟识别结果作为功能完成。

## 2. 当前项目接入点

- `lib/media/engine/media_kit_engine.dart`：media_kit / mpv 原生播放链路，无浏览器 SourceBuffer。
- `lib/media/gateway/media_gateway.dart`：受控回环网关，负责清单重写、缓存与网络请求。
- `lib/media/cache/segment_prefetcher.dart`：已有分片预取，但没有内容检测门禁。
- `lib/media/hls/ad_filter.dart`：已支持静态、未加密 TS 清单中的成对 CUE-OUT / CUE-IN；明确不把 discontinuity 单独作为广告证据。
- `lib/features/playback/application/playback_controller.dart`：管理切集、拖动、恢复、进度和用户跳过标记。
- `lib/media/hls/timeline.dart`：已有删减前后时间映射；动态跳过必须避免重复换算。
- `lib/media/export/ffmpeg_exporter.dart`：已有 FFmpegKit 依赖，可评估复用原生解码能力；检测采样应建立独立适配器。

## 3. 原提案需要修正的假设

1. `EXT-X-DISCONTINUITY` 表示格式、轨道或时间戳等不连续，并不是成对的广告开闭标签。只能作为候选边界；删除区间必须另有证据。
2. 广告命中不是单调函数。一次步进抽样未命中不能证明前面所有内容都是广告，也不能证明当前分片安全。不能直接使用二分法跨越未确认内容。
3. `SourceBuffer.timestampOffset` 属于浏览器 MSE 接口，不适用于本项目现有 mpv 链路。采用原始时间轴上的动态 SkipRanges 和精确 seek 作为首选接入方式。
4. seek 的延迟受到关键帧、源站与解码器影响。终点预热能降低等待，但零黑屏、零卡顿必须以实测为准，不能作为无条件保证。
5. MP4 的 `stss` 是同步样本编号；时间和字节定位还依赖其他样本表。FLV 不是 MP4。优先复用解复用器定位能力，不把任意字节块等同于可独立解码片段。
6. 固定口播和背景音乐匹配需要参考样本；主题词匹配需要真实 ASR/OCR。地域词单独出现不能直接判定为广告。
7. 在直播源末端，未来 15–30 秒内容可能尚不存在；超前检测需要引入相应播放延迟。直播是否纳入本轮须明确。
8. 角落横幅与正片可能同时存在。跳过整个片段会损失正片；局部遮挡属于不同处理能力，需独立确认。

## 4. 原设计审查清单

本节保留实施前的审查范围；最终交付方式与边界以上文及第 8 节为准。

### 阶段一：检测与调度核心

- 定义样本来源、检测器、检测证据、区间决策与策略接口。
- 区分命中、未命中、未完成、不可检测、失败，不用空结果伪装通过。
- 引入可取消的会话级探测调度器，目标窗口为播放位置前方 15–30 秒。
- 首播、拖动、切集、切清晰度后重新建立窗口，丢弃旧会话回调。
- 按实际播放速度调节预算，限制并发、内存、磁盘与检测耗时。

### 阶段二：真实检测适配器

- 通过 FFmpeg 采样音频和可解码画面，复用现有网络安全边界。
- 音频指纹匹配参考广告样本；ASR 与 OCR 提取有时间信息的文本证据。
- 组合品牌、推广话术、重复画面和音频证据，避免仅凭“澳门”等地名自动删除。
- 离线模型的下载来源、校验、许可证、资源占用及可用平台在选型后明确。
- 若选远程服务，明确传输内容、认证、超时和用户启用方式。
- 将模型缺失、启动失败和检测能力不足显示为明确状态。

### 阶段三：播放及网络控制

- 将已确认区间注册到播放控制器，合并重叠区间，支持禁用和误判撤销。
- 保留原片时间坐标，与已有显式标签删减时间轴组合时只转换一次。
- HLS 共享探测与播放缓存；仅在区间已经确认且恢复点可播放时停止相应预取。
- 已交给 mpv 的数据由 seek 驱动切换，不能用简单返回空分片或 HTTP 错误模拟跳过。
- 研究网关门禁与播放器读超前协调，避免 mpv 提前下载完广告导致带宽优化失效。
- MP4 / FLV 通过解复用器与 Range 能力采样及跳转；检测服务器不支持 Range 等限制并明确降级。
- 加密 HLS、独立音轨、多变体与直播分别建立能力判断，不静默宣称全部可检测。
- 网络过滤和播放控制共享取消机制，避免旧探测占用新一集资源。

### 阶段四：用户设置与验收

- 添加独立的内容检测开关、检测状态、命中原因与临时停用入口。
- 既有监管模式与设置权限必须继续生效，失败策略不能绕过用户选择。
- 覆盖取消、超时、乱序完成、首播、拖动、暂停、倍速、切集、切清晰度和退出。
- 用受控 HLS 与 Range HTTP 服务验证请求日志：确认跳过范围、恢复点和未请求的分片。
- 测试已有静态过滤、历史进度、下载与用户跳过标记不回归。
- 使用真实广告与正常内容样本测量识别准确性、误删、漏检、延迟与资源使用。
- 运行静态分析、源码大小检查、相关自动化测试与原生播放验证；Flutter 构建和平台测试串行执行。

## 5. 用户确认记录

- 本机离线模型，允许首次下载；不使用云端识别服务。
- 检测来不及、失败或结果不确定时暂停等待，不自动放行原片。
- 未提供真实素材；重点是澳门、新葡京、缅北、赌场、www、真人等大字画面和口播主题词。
- 范围为博彩与引流广告；不引入无文字成人/暴力分类模型。
- 原要求 Windows / Android 的 HLS、MP4、FLV 均验收。Android WHPX 0x80070005、软件模拟启动失败且无连接设备后，用户同意先完成 Android 构建，运行验收等待设备就绪。

## 6. 验收边界

模型接口可注入不等于识别功能可用；没有真实检测后端不能验收为完成。
没有真实素材只能验收调度和播放机制，不能声称已验证广告识别准确率。
只完成自动 seek 不能声称已实现广告区间零下载；必须查看源站请求日志。
“尽量平滑跳过”和“完全无缝拼接”应分开验收。若必须重写时间戳并持续无缝输出，应作为独立的重封装管线设计与性能评估。

## 8. 实现结构与可复现验收

- lib/media/content_filter：策略、离线模型管理、OCR/ASR 线程、FFmpeg 采样、已批准媒体服务和时间映射分别独立；不往 mpv 填入未检测原片。
- DeclaredAdSampler 仅负责网关清单删减后的坐标换算；FilterSession 管理原片坐标、判定与有界生产；ApprovedTimeline 管理最终播放到原片的映射。
- 设置开关默认关闭，检测状态和累计过滤秒数展示在播放界面；关闭仍遵守已有监管授权。
- 退出/切集取消旧检测，旧结果不得发布；模型线程在 native 调用返回后自行释放，加载阶段提前提供关闭通道。
- Windows 验收使用真实 PP-OCRv4、SenseVoice 和 mpv。16 秒素材中 4–12 秒广告应移除，保留 8 秒；48 秒长素材中 16–24 秒广告应移除，保留 40 秒，并验证清单增补、从零起播、缓存滚动及原片时间。
