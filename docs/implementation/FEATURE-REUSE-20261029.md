# 内容特征复用与基础过滤改造 · 2026-10-29

## 已确认方案

- 默认跳过时长 20 秒；保留明确保存过的用户设置。
- 播放状态提示独立计时 3 秒，暂停不显示，控制栏重显不重复展示。
- 区分本集固定区间、频道内容特征、全剧内容特征。以内容匹配为主，原集时间点不作为其他集的跳过依据。
- 三种用户策略：保守自动（默认）、积极自动、提示后跳过。
- 管理支持预览、启停、名称/作用范围/偏移编辑、重新提取、删除和本地状态；不引入独立导入导出或批量管理。

## 设计与实现

### 范围与持久化

`FeatureRule` 存储 `scope` 与 `seriesKey`，仓库按当前频道和作品身份筛选。频道范围覆盖该来源所有影片；全剧范围基于标题、年份（缺失时导演）、类型与版本建立身份。身份不足时限制在来源内的作品 ID，避免仅凭模糊标题跨源扩散。已有频道规则无需重新采集即可继续频道匹配；没有作品身份的旧规则改成全剧前须重新提取。

编辑与重新提取沿用规则 ID。取消/失败不覆盖旧样本，重新提取保留启用状态。当前播放内容必须属于规则范围；异步采集与保存检查播放代次，切集后过期结果不能落库。

### 不依赖增强资源的匹配

- 采集保留 250ms 音频频谱和 500ms 画面序列；后台候选使用 50ms 滑动音频窗口和 250ms 画面网格，降低内容起点偏移导致的漏检。
- 每次探测前进 4 秒，内容特征多取 500ms 重叠数据，跨片段保持连续证据。拖动或不连续采样重置历史；取消后不提交匹配状态。
- 保守模式要求完整有序序列、高平均相似度及足够强匹配帧。静音、纯色等不作为同一内容的证据。
- 积极模式降低有限阈值，并尝试 0.96/1/1.04 的时间比例；仍要求完整序列，不以音量或单帧判广告。
- 指纹提取和序列匹配在工作 isolate 执行，后台最多一个采样任务，不阻塞视频输出。
- 额外画面密度不改变可选 OCR 的 500ms 时间定位与推理频率。
- 修复静音转声音边界处频谱峰值为零导致的 NaN 转整数错误。

### 播放与管理

提示策略仅创建候选，用户确认才 seek；忽略/撤销豁免本次访问，主动拖动重新检测。候选本身不截断后续采样。管理页显示适用范围、启用状态与本地检测状态，支持搜索和范围/停用筛选；编辑页预览缩略图或音频频谱，重新提取可调整样本区间与音画模式。

## 使用边界

基础能力匹配用户标注的重复声画，不能在没有参考样本时理解未知广告语义。明显换配音、裁剪、重新剪辑需重新提取；积极模式增加误跳风险。网络/CPU 较慢时可能晚发现，只能跳过剩余部分。本轮无真实频道准确率评估、无 Android 实机性能验收，也未自动下载增强资源或改写用户实际数据库。
