# Zero Player v0.0.9

发布日期：2026-11-01（Asia/Shanghai）；源码及 Windows 二进制版本：0.0.9+9。

本次发行提供 Windows x64 安装包和便携包。Android 最新正式公开包仍为 [v0.0.7](https://github.com/yixunfei/zero-player/releases/tag/v0.0.7)：原正式签名文件当前不可用，独立包名的测试签名构建不作为正式附件。

## 更新内容

- 新增在线音乐，支持榜单和编辑精选歌单、歌名/歌手搜索、多源并发与逐步显示；可选择独立渠道，渠道偏好保存在本机。
- 支持整理播放队列、歌单、四种播放模式、历史续播、迷你播放器及 Windows 托盘音频控制；音乐与广播互相暂停，播放视频时暂停音频。
- 支持可下载渠道的离线任务、暂停续传和完整性检查；已下载歌曲在搜索中优先显示，源站不可用时仍可播放本地文件。跨渠道匹配有歧义时保留不同结果。
- 歌单与播放历史纳入普通备份；下载文件与任务不随备份迁移。音乐继续遵守现有监管、内容过滤和受控网络策略，不执行远程音源脚本。

## 验证与限制

此前对相同业务源码完成 611 项单元/组件回归，5 项按配置跳过；Windows 原生离线业务验证覆盖两首下载、关闭源站后解码、续播和队列连播。此前的真实音源短时验证涵盖 MY FREE MP3、米兔、musicBox 及部分实验音源，不代表本次对所有源站的实时可用性或长时间播放已验收。源站、地域与授权条件可能影响歌曲播放和下载。

Android/TV 实机、系统后台和长时间播放未验收；本次未重新验收安装/卸载及文件关联。Windows 二进制未做商业代码签名。离线搜索匹配依赖歌曲元数据；不同版本或有歧义的匹配不会强制合并。
