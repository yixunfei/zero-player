# Zero Player v0.0.8

发布日期：2026-10-31（Asia/Shanghai）；源码及 Windows 二进制版本：0.0.8+8。

本次发行仅提供 Windows x64。Android 最新正式公开包仍为 [v0.0.7](https://github.com/yixunfei/zero-player/releases/tag/v0.0.7)：原项目正式签名文件当前不可用，独立包名、测试签名的 Android Release 不上传为正式附件。

## 更新内容

- 新增本地视频入口、续播及观看记录，可通过 Windows 打开方式启动视频；已运行时安全转发到原窗口，支持隐藏/最小化窗口恢复。
- 下载支持指定目录、完成后自动合并保存 MP4、重新选择目录。下载缓存与保存状态分开，持久化保存意图及摘要，退出或中断后可恢复；不覆盖用户视频，删除任务保留已导出的文件。
- 播放器增加内嵌音轨/字幕选择，修复普通 MP4 导出、本地续播、离线标记入口、手机横屏弹窗、电视焦点和窗口恢复等问题。
- Windows 安装时可选常见视频格式关联，默认应用由用户在系统设置中选择。数据目录独占保护防止多实例同时清理下载缓存。
- 完善广播/直播预检目录、备用线路、媒体健康与节目表；搜索默认全渠道、优先当前来源，支持手动限定来源。
- 保留内容过滤、监管验证、网络策略和恢复码边界；本地视频仍按现有监管策略处理。Android 源码补充流式选择、缓存配额/清理与文档身份管理。

## 验证与限制

本轮发行基于已复查的相同业务源码：555 项单元/组件回归通过，2 项按原配置跳过；4 项 Windows 原生业务验证通过，覆盖跨进程隐藏窗口转发、实际解码/跳转/续播、HLS 下载保存和小窗/全屏恢复。静态分析、源码规模、12 项发布工具回归及普通 Windows Release 构建通过。原生 driver 有既有插件检测提示，实际业务结果和退出码均成功。

安装后 Shell 文件关联/卸载、Android/TV 实机、真实用户媒体的长期播放尚未验收。合成样本和本机回归不能保证所有来源可播放、所有编码可解码或内容零漏检。广播仍为实验功能；Windows 二进制未做商业 Authenticode 签名。
