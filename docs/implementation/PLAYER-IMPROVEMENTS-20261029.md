# 收藏渠道、播放器与时间轴完善

日期：2026-10-29；基于当前本地工作区，应用版本仍为 0.0.6+6，未提交或发布线上。

## 实现

1. 详情页增加持久化收藏渠道操作；搜索请求队列、结果排序、渠道标签共用 source_order 优先级，入口优先，其后收藏、已验证可用、未知。收藏变化下次搜索生效。
2. 将常用操作提取为 PlayerTransport；时间、缓冲位置、倍速、快捷标记、比例、音量与截图有直接入口。控件支持窄屏横向滚动；方向键、Shift 跳转、空格与三秒自动隐藏具备回归测试。
3. 用户特征采集与后台检测统一 ProbeSampler；只提取所选模态，播放不重编码。历史样本、命中抑制与检测游标在时间轴回退后重置；手动 seek 重新启用区间，撤销保留本次豁免。未知时长不再将 seek 截成零，失败的 seek 清理等待状态。
4. 可选增强检测失败或不确定不覆盖用户特征命中。检测异步串行、取消后丢弃旧结果；仍保持播放流畅优先，不能保证广告播放前完全拦截。
5. 对带 discontinuity 的有限 TS 点播清单，使用 EXTINF 坐标修正 PES PTS/DTS、PCR/OPCR，保留音视频相对时差及编码负载。原始缓存与修正缓存隔离；后台 isolate，单段上限 16 MiB。加密、MAP、BYTERANGE、重复 URI、直播以及不能解析的 TS 不改写。时钟异常本身不被当成广告证据。
6. ARM64 APK 压缩原生库，保留编解码库、全部三套中文字体及功能；可选模型/推理运行库仍手动安装。手机构建预算改为 70 MiB，并验证字体和压缩方式。

- flutter test --no-pub：397 项通过，2 项公开网络测试按原配置跳过。
- 独立回归覆盖：收藏持久化和搜索顺序；320px/568px 与 1.6 字体下控制栏；控制栏隐藏、底部唤出、画面点击、方向键；特征回退重命中、增强失败、失败 seek、撤销；TS 时间戳与 33 位回绕。
