# Zero Player v0.0.13 预发行

版本 `0.0.13+13`，2026-11-09。提供 Windows x64 安装器、便携包和 Android ARM64 开发测试包，以及源码、第三方声明、原生来源和 SHA-256 清单。Android 为独立包名 dev.zeroplayer.zero_player.devtest，名称「Zero Player 测试」，使用已有测试签名，与正式版隔离。

- 在线音乐支持随机播放搜索结果、按歌手筛选和主题关键词快捷搜索。
- 支持手动指定播放渠道及默认关闭的播放失败自动换源；匹配同名同歌手、保留进度，每轮避免重复尝试渠道。
- 整合酷狗公开音频直连、网易云同步歌词和公开歌单导入、默认聚合搜索及收藏渠道优先。
- 修复音乐聚合搜索取消后仍等待底层超时的问题。
- 修复发现页后台停用当前频道时意外清空内容并回顶；保留内容过滤和监管策略。

自动换源开关当前会话有效；严格元数据匹配可能漏掉写法不同的同曲。主题使用渠道关键词检索，不是语义推荐。跨渠道换源公网实际解码和 Android/TV 真机未专项验收，历史版本已知原生问题不因本次源码更新视为关闭。验证结果以 STATUS.md 为准。
