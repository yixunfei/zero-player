# v0.0.7 审核与修复记录

日期：2026-10-29。用户确认接手当前内容过滤分支的全部未提交工作，完成审核、修复、测试后合并 main 并发布 Windows x64 / Android ARM64；Android 无设备时明确记录限制。两名子 Agent 仅作只读审查，主会话统一修改和串行构建。

## 本轮修复

1. 监管模式下，远端订阅刷新不再通过无授权的 LiveRepository 自动新增启用直播列表。组合服务复用带监管回调的仓储；无授权刷新只更新既有列表，新列表在发起网络请求前跳过，保留已有停用状态。
2. 成人分类逐项检查分隔后的地区分类，修复“韩国伦理,剧情”等复合分类漏判，保留普通词的非成人行为。
3. 备份纳入并校验 `content_label:*`，恢复时替换旧标签，普通历史保持可见且受限内容仍被当前策略过滤。恢复完成来源/设置缓存重建后统一通知策略消费者。
4. 过滤设置使用受控下拉框。取消或错误监管密码后，仍显示已保存的时长和策略。
5. 强特征以完整覆盖去重，保留部分重叠内容的尾部；弱关键词仍不能延长已确认边界。
6. 混合采样先识别可用轨道，缺失音轨不再使画面规则失效，缺失画轨不再使声音规则失效；单模态保留轻量路径。
7. KWS 接入重叠音频前的上下文且不复制重叠内容；seek/reset 显式清空尾音和命中抑制状态。真实口播测试定位澳门 1120ms，连续、500ms 重叠和重置后重播均覆盖。
8. 长规则根据两锚点证据范围及尾部空缺计算回看，覆盖稀疏锚点与采样失败后的缺口。回看可能增加检测时间，不保证末尾续播能即时跳过。
9. OCR 低置信度不再提前屏蔽后续清晰画面或 ASR；不确定结果只在无确定命中时返回。ASR 原生 stream 在交付惰性证据前释放，避免提前返回造成泄漏。
10. 特征更新以最终集合检查每渠道 100 条/总计 500 条，防止跨渠道重新提取后超额导致备份失败。
11. 设置、许可证页、播放诊断与 pubspec 统一版本；发布工具新增 Windows + ARM64 组合以及 APK 内嵌版本核验，防止混入旧产物。

## 测试约定

回归使用临时数据库、受控回环媒体服务和合成图片/语音；不改用户真实数据库。Windows 平台测试和发布构建串行，每个原生测试文件独立进程和短 TEMP/TMP。公开网络用例保留原有默认跳过。最终结果及分发范围记录于 `RELEASE-0.0.7.md`。

既有 `background_playback_controller_test.dart` 仍假设旧版关键词自动跳过，已按当前明确的“关键词先确认”产品策略修正，验证确认前不跳、确认后跳、撤销恢复。首次批量执行因 TEMP 逐层嵌套触发 Windows 路径上限；更正执行路径后重新运行，失败记录不计入通过数。

原生壳回归改为点击滚动收起导航后的浮动入口，并明确断言旧按钮不可点击。历史严格管线的模型播放测试原先直接期待关键词自动剔除，现增加真实 OCR 证据需要确认的断言；剔除及滑动清单测试则显式提取已批准声画特征，保留原有区间、画面及尾部续播断言。Android 系统栏用例只允许在 Android 上执行，避免将桌面跳过误记作实机通过。

产品回归同步当前暂停/速率图标的可访问标签，并验证窄屏横向工具栏可滚动访问音量。原生 `setSurfaceSize` 不会同步 View 的 MediaQuery 指标，手机布局模拟同时设置物理尺寸并在结束时恢复，避免将桌面布局误当作手机布局通过。
