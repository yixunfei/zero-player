# v0.7.3 预发行

应用版本为 `0.7.3+73`。提供 Windows x64 安装器和便携包、Android ARM64 开发测试 APK，以及源码、第三方声明、原生组件来源和 SHA-256 校验清单。

- 修复不同直播频道共用同一播放地址时，请求头被另一个频道覆盖的问题。
- 测活收到媒体数据后，如果保存结果失败，界面显示检测未完成，并保留原有状态。
- 直播搜索显示当前分组范围，无匹配时可直接切换到全部频道继续搜索。窄屏保留选中频道名称及操作，测活列表显示等待检测的频道。
- 纳入 v0.7.2 后更新的随包直播精选、体育直播分组和追剧资源手动同步。频道、线路及测活记录见[直播源维护说明](LIVE_SOURCES.md)。

Android 开发测试 APK 沿用独立包名 `dev.zeroplayer.zero_player.devtest` 和开发测试签名。Android/TV 实机、安装卸载和长时间播放待验收。验证记录见[实施状态](STATUS.md)。
