# Zero Player v0.0.12 预发行

版本 `0.0.12+12`。本版用于播放稳定性修复与真机复测，提供 Windows x64 安装器／便携包及 Android ARM64 开发测试包。

- 修复可恢复的原生警告误触发重新播放；持续推进时取消恢复，暂停、后台及监管屏蔽期间不由看门狗重开。
- 保留中断前的有效进度，覆盖“先清零后报错”和“先报错后清零”两种顺序。续播先确认跳转，资源时长不足时提示换线并保留进度。
- 动态 HLS 清单绕过旧分片缓存；清单改变后清除旧时间轴修正表。静态缓存、显式广告标记过滤及网络访问边界保留。
- 清理播放器停止后遗留的旧媒体列表引用；增加保留位置、倍速和暂停意图的软件解码画面恢复，以及有界退出等待。
- 手机新增“跟随系统／横屏播放／自动旋转”菜单，保存选择，退出恢复系统方向。
- 增加两份有界本机诊断快照，重启后保留上次未正常结束的记录；可导出内存、画面输出、资源状态和系统历史退出原因，不记录原始播放地址、凭据或媒体。
- 纳入前一轮线路显示、首次点击唤出控件、常驻解锁、换集画质隔离和旧片段弹窗会话保护。

Android 开发测试包为 Release 编译，名称「Zero Player 测试」，包名 `dev.zeroplayer.zero_player.devtest`，沿用已有测试签名，可覆盖同签名测试版并保留数据，与正式版隔离。Android 正式签名仍不可用，最新正式 Android 包保持 v0.0.7。

功能修复的普通回归 669 项通过、8 项公网用例按配置跳过；静态分析和规模检查通过。Windows 原生播放恢复、触摸交互及独立音视频采样通过；Android 方向菜单核对了实际横屏、传感器模式请求、保存与系统方向恢复。详细构建、版本与附件校验结果见 STATUS.md。

已知限制：Android 视频回归在两种模拟器图形后端遇到 EGL 上下文创建失败；Windows HLS 特征采样路径两次发生原生进程结束，原因未定位。用户反馈发生在默认关闭特征跳过时，未将该可选采样路径认定为手机故障原因。真实手机／TV、厂商硬解码、长时播放、低内存回收和安装卸载尚未验收，不能宣称三个随机故障已全部消失。未标记或嵌入视频的源站广告仍可能存在。

请沿用默认配置复测；如再异常，重新打开任意视频，在“选集与设置 → 播放诊断”保存文本。
